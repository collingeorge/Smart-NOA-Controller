## Deliberately not changed

- **Code finding 13 (CSP/frame-ancestors as HTTP headers).** These need the hosting server's configuration. A static repository cannot set response headers, and `frame-ancestors` is ignored in a meta tag. The meta CSP is unchanged.
- **Ketorolac rules for "prophylactic before major surgery" and "intraoperative haemostasis" stay as warnings, not locks.** The simulator cannot know whether surgery is major or whether haemostasis is critical. Both show the label wording.
- **Fentanyl elderly dose.** The label gives no reduced figure, so none was invented. The warning asks the user to reduce the dose.
- **Lidocaine WPW** was also made a LOCK, because the S28 label lists it among the contraindications.
- **MAC obese-OSA example.** After the midazolam recalibration it holds "moderate" only briefly before the procedure starts, and is then mostly "minimal". The plan doses are label lower bounds, so this outcome comes from the illustrative model and is not a dosing change.
- **`EXAMPLE_RESULTS.json`.** The Python fixes do not change any example output. The regenerated output is byte-identical.
